# nn-learning

План изучения нейросетей: от перцептрона до мультиагентных систем.
Нагрузка: 1 час в день, старт 27.10.2026, финиш 17.05.2027.

## Структура
- `notebooks/` — ноутбуки по неделям (w01_..., w02_...)
- `src/` — собственный код (утилиты, NumPy-MLP)
- `reports/` — конспекты и итоги этапов
- `data/`, `models/` — данные и чекпойнты (в git не хранятся)

## Запуск
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
